IMPROVED CHAT - COMPANION-FREE BETA

1. Close Civilization V.
2. Extract your download. Copy the inner InGameTranslateMod folder into your
   Civilization V installation's Assets\DLC folder, replacing the old copy.
   Keep only one copy installed. This is the same installation style as EUI.
3. Start Civ V and join a multiplayer lobby or game. Translation works in the
   game's own chat. No Settings step is needed.

No companion, installer, account, or API key entry is required.
Do not share your downloaded ZIP: it contains your installation key. Share
https://civ5-improved-chat-api.pages.dev/ so friends receive their own keys.

IN THE CHAT
Other alphabets are translated by themselves, on the message's own line. Hover
a line to see the original. The small T on a line translates it, < shows the
original again, and right-clicking T lets you choose the message's language.
Right-click a line for player notes and history.
On the chat row, TR: - means you send exactly what you type. Pick a language
under TR and each message is translated before it is sent, to whoever is
chosen in the game's To: list. Your choice is remembered. The ... button opens
settings (languages, icons, colours), player notes and encounter history.
If another mod replaces the game's chat script, Improved Chat opens as a
separate window with the same features. Existing notes/history are kept.
Windows clipboard Copy/Paste buttons are unavailable in this version.

Translation sends selected message text to the hosted Cloudflare service.
Notes and history remain local. The first request leaving Civ V contains
authenticated ciphertext because its native HTTP API does not start TLS
reliably. Keys are delivered only in the HTTPS download. The cryptographic
implementation is experimental and has not received an independent audit.
Traffic timing, length and installation identifiers are not hidden.

Incoming chat is translated into your language: the language Civ V runs in,
or the one chosen under Settings > My language, which also sets the window
language (ten languages). Civ V only shows the letters of its own language,
so a Russian, Polish, Korean, Japanese or Chinese window needs the game in
that language; German, French, Spanish and Italian work in any Western game. Send in: offers 31 languages; Russian (Latin letters) is readable
in every game. Translations know the game's official names and player slang.

Messages are limited to 6,000 UTF-8 bytes before translation. Long messages
can consume several translation requests. Default daily limits are 2,000
requests / 100,000 input bytes per installation, with shared service/network
limits. A failed translation is not silently sent in its original language.
The service recognises the message language; right-click Translate to choose
it yourself. Russian transliteration is best effort. When a player floods the
chat, automatic translation is rationed; each message keeps its Translate
button, and your own messages are always translated first.

The ZIP is personal. Copying it to multiple PCs shares the allowance and can
cause replay-counter conflicts. Request a separate download for each PC.
If local data is deleted or restored from backup, get a fresh download.
Do not repeatedly download to evade service limits. Public download limits
are shared by users on the same network.

Works with any mod or DLC, with or without EUI. Copy the folder into
Assets\DLC. No extra step, and EUI's files are not changed. A mod with its own
chat script (KEK Mod, for one) gets the separate translator window instead. Multiplayer stability needs real-game
testing; a successful main-menu test does not prove it.
To uninstall, close Civ V and remove Assets\DLC\InGameTranslateMod.
