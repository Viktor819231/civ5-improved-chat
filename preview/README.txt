Open index.html in a browser. No server, installation or API credentials are
required. All displayed chat, notes and history are demonstration data.

Try compact/expanded/collapsed modes, tabs, outgoing language, recipient,
translation toggles, per-message Original/Translate and draft entry. Switching
settings never submits the draft. Send/Enter adds a local demonstration row.
Turn numbers are shown on message hover. Drag the header to move the window;
double-click it or use Compact/Expand to switch sizes. Both sizes use the
same chat styling and remember separate positions within the preview session.

The canvas starts at1280x900 and scales to the available browser area. Display
size can be switched to16:9,16:10,4:3 or ultrawide presets. Window dimensions
are capped to the chosen display, matching the native bounds. Settings offers
the Small/Medium/Large presets. The smiley opens sample icon insertion;
right-click a username for sample notes/details. Local aliases appear as
OriginalName(nickname). All names/history/counts in this preview are samples.
Width/height/opacity can be adjusted in the inspector; Download layout choices
saves those choices for the next native game-UI revision. It does not directly
modify installed DLC files. This is a visual approximation, not a Civ engine
emulator. Native fonts, widgets, wrapping and focus still require an in-game
check. The matching XML/Lua simplification is in the DLC/UI source.
